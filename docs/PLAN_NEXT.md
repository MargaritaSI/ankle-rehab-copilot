# Rehab Copilot — work plan for parallel agents (after the 2026-10-30 submission)

Rules for every agent: one agent per file set, no two writers on one file. `main` auto-deploys the
public demo, so test locally first (`.venv/bin/streamlit run app/app.py --server.port 851N`), then
push. Backend logic lives in `endpoint/`; UI in `app/`; knowledge in `corpus/`. Every new behaviour
gets a case in `eval/eval_edge.py` or `eval/eval_answers.py`. Tag the submitted state first:
`git tag submission-2026-10-30 && git push --tags`.

| # | Workstream | Files it owns | Model | Done when |
|---|---|---|---|---|
| A | **Scenario engine** — a 5th tab "What if": pick an activity (walk / stairs / swim / bike / run / standing work / strength) and an intensity vs today (less / same / more); output = likely 2-week and 3-month course, what it trains, what can go wrong, first warning signs, step-back rule; modifiers from the profile (sex, age band, revision, poor perfusion). Use `corpus/kb/scenarios_predictions.json` (27 notes) as the first tier plus the `overload_cartilage`, `underload_cartilage`, `load_progression_criteria`, `perfusion_poor_healing`, `revision_vs_primary_rehab` papers. | `endpoint/scenario.py` (new), one function `scenario(profile, activity, delta, lang)`; strings via a message to the UI owner | Opus | 6 activities × 3 deltas produce cited, language-consistent output; 10 cases in `eval/eval_scenarios.py` pass (every numeric claim cited, no English in RU) |
| B | **Nerve & water block** — curate 15–25 notes from the new papers on superficial-peroneal / sural nerve irritation after ankle arthroscopy, recovery times, when to pause vs continue, hydrostatic pressure and immersion effects, aquatic session dosing (minutes, frequency, water temperature), kick technique load on the ankle. Write them as `corpus/kb/nerves_water.json` (same schema: topic, source_title, source_url, chunk_idx, text), each note ≤ 120 words with the PMCID in `source_url`. The author's n=1 note stays separate and labelled. | `corpus/kb/nerves_water.json` (new) | Sonnet | Ask "numbness after swimming" returns ≥ 2 paper-backed notes before the n=1 note; the KB index rebuilds on start (fingerprint change) |
